# Python FastAPI Foundations

You will build this project yourself, in small daily increments.

## Final outcome

A tested API for managing learning tasks. It will eventually include PostgreSQL persistence, user authentication, input validation, structured logging, Docker, and a clear API contract.

## Build order

1. Create a Python virtual environment and verify it is active.
2. Create a minimal FastAPI application with a health endpoint.
3. Add Pydantic request and response models.
4. Add in-memory task CRUD with tests.
5. Replace in-memory data with PostgreSQL.
6. Add authentication and authorization.
7. Add structured logging and consistent error responses.
8. Add Docker and a deployment-ready README.

Do not begin later items until you can explain and test the current item.
