# Week 1 - Python Rebuild and First API

Outcome: regain Python confidence and build a small, tested FastAPI application without copying a tutorial.

## Day 1 - Python environment and core refresh

- Build a task-summary script with lists, dictionaries, functions, loops, conditions, and type hints.
- Learn virtual environments and explain the core data structures in your own words.

## Day 2 - Functions modules errors and files

- Split the task script into modules.
- Read and write task data as JSON.
- Add predictable exceptions and error messages.

## Day 3 - Testing fundamentals

- Learn pytest fundamentals.
- Test the task functions, including success and failure cases.
- Learn assertions, test naming, and why repeatable tests matter.

## Day 4 - HTTP and FastAPI introduction

- Learn request, response, status code, JSON, endpoint, and API concepts.
- Create the FastAPI health endpoint and test it.

## Day 5 - Validated task API

- Use Pydantic request and response models.
- Build in-memory create, read, update, and complete task endpoints.
- Test the API behavior.

## Day 6 - Consolidation and explanation

- Clean up the README and tests.
- Explain the code path from HTTP request to Python function to JSON response.
- Create a short demo and reflection.

## End of week success criteria

- You can explain variables, functions, type hints, lists, dictionaries, modules, exceptions, JSON, tests, HTTP, endpoints, and status codes.
- You can build and test a small FastAPI API with only documentation as reference.
- The repository contains one clean, explainable project increment and six honest daily logs.
